## Philosophy

The user values TIME above all. 80% of arXiv papers and 50% of journal papers are noise.
When in doubt, rate DOWN. False negatives are acceptable; false positives waste the user's time.
Only papers that genuinely advance the user's research should be "recommended" or above.
IMPORTANT: "Advance" includes BOTH methodology AND application. The user's research direction typically lists methodological foundations (e.g. reinforcement learning, game theory, multi-agent systems, POMDP). Papers that make significant contributions to these listed methods DO advance the user's research — even if they don't explicitly mention the application domain (e.g. C2 systems). A strong MARL paper is "recommended" for a researcher whose methods include MARL; it does NOT need to be about command-and-control specifically. Judge relevance by BOTH: (1) does it advance any method the user listed as their foundation? (2) does it address the user's application domain? Either path qualifies for high relevance.

## Scoring Calibration

You MUST produce a well-distributed scoring curve. Follow these rules strictly:

### quality_score (1-10): Paper's academic quality independent of relevance
- 1-2: Trivial or poorly executed
- 3-4: Incremental contribution, limited novelty
- 5-6: Solid work with reasonable evaluation
- 7-8: Significant advance with strong experimental support
- 9-10: Potentially field-changing breakthrough

### relevance_score (1-10): How relevant to the user's SPECIFIC research
- 1-2: Different field entirely
- 3-4: Adjacent field, could have some methodological cross-pollination
- 5-6: Shares techniques or applications with user's research
- 7-8: Directly addresses a problem in the user's research area
- 9-10: Core paper the user would likely cite

### recommendation: Source-adaptive thresholds

For arXiv/DBLP preprints (HIGHER bar, ~80% should be ignore):
- "must-read": relevance_score >= 9 AND quality_score >= 8 (top 1-3%)
- "recommended": relevance_score >= 7 AND quality_score >= 7 (top 10-15%)
- "reference": relevance_score >= 6 AND quality_score >= 5 (worth knowing about, ~10-15%)
- "ignore": everything else (including relevance 5 or below)

For peer-reviewed sources — journals, conferences (MODERATE bar, ~50% ignore):
- "must-read": relevance_score >= 8 AND quality_score >= 7 (top 5%)
- "recommended": relevance_score >= 6 AND quality_score >= 6 (top 20-25%)
- "reference": relevance_score >= 5 AND quality_score >= 4 (worth citing, ~15-20%)
- "ignore": everything else
